# CLAUDE.md

## О проекте
Лендинг для кав'ярні-обсмажувальні «Пара», Дніпро (название и контакты — заглушки). Цель сайта: посетитель пишет в Telegram (звонок — запасной вариант).
Главная фишка — анимации уровня Awwwards, но сайт обязан быстро грузиться и нормально работать на телефоне.
Язык текстов на сайте: украинский.

## Стек
- Чистый HTML + CSS + JS, без сборщика и фреймворков. Хостинг — GitHub Pages.
- GSAP + ScrollTrigger + SplitText (все плагины GSAP бесплатные), Lenis для плавного скролла.
- three.js — максимум один эффект в hero и только если он реально нужен; обязательно с фоллбеком.
- Библиотеки подключать через CDN (jsDelivr или cdnjs) с точной версией, никогда `@latest`.
- Выбранные версии (jsDelivr): gsap 3.15.1 (gsap, ScrollTrigger, SplitText), lenis 1.3.27. three.js не используется: пар в hero — один шейдер на чистом WebGL (`js/anim/steam.js`).

## Окружение и команды
- Windows, терминал Git Bash. В путях использовать `/`.
- Локальный сервер: `python -m http.server 8000` (если не работает: `py -m http.server 8000`), открыть http://localhost:8000.
  Через file:// сайт не открывать — модули не загрузятся.
- Скриншоты для самопроверки: `node scripts/shots.mjs` → папка `shots/`.
  Если скрипта нет — создай его на Playwright (`npm i -D playwright`, `npx playwright install chromium`):
  он плавно прокручивает страницу до конца, чтобы сработали все ScrollTrigger, и снимает ширину 375, 768 и 1440 px.
- В `.gitignore`: `node_modules/`, `shots/`.

## Структура
```
index.html
css/tokens.css     — CSS-переменные: цвета, шрифты, шкала размеров, отступы. Цвета и шрифты задаются только здесь
css/base.css       — сброс, типографика, общие классы
css/sections.css   — стили секций, в том же порядке, что в index.html
js/main.js         — точка входа: плагины, Lenis, прелоадер, запуск анимаций
js/anim/*.js       — по файлу на секцию (hero.js, gallery.js…), каждый экспортирует init()
js/cursor.js       — кастомный курсор и магнитные кнопки
assets/img/        — только WebP
scripts/shots.mjs  — скриншоты
CREDITS.md         — источник и лицензия каждой картинки и шрифта
```
Имена папок не начинать с `_` — GitHub Pages (Jekyll) их скрывает.

## Дизайн
- Сначала дизайн-план, потом код: палитра из 4–6 hex-цветов, шрифты и их роли, идея раскладки.
  Проверь план: если он выглядит как то, что получилось бы для любого похожего сайта, — переделай под этот бизнес.
  Итог запиши в раздел «Дизайн-система» внизу и дальше держись его.
- Без шаблонных «ИИ-приёмов», если я сам о них не попросил:
  - кремовый фон + терракотовый акцент; почти чёрный фон + один кислотно-зелёный акцент
  - одинаковые скруглённые карточки с одной и той же серой тенью, градиенты ради украшения
  - КАПС-подписи над каждым заголовком, нумерация 01/02/03 там, где нет последовательности,
    стрелка «→» на каждой кнопке, одно слово в заголовке выделено курсивом или цветом
- Смелость в одном месте: один запоминающийся элемент, всё вокруг спокойное.
- Шрифты: Google Fonts с кириллицей, не больше двух семейств, `display=swap`, preconnect.

## Анимации
- Анимировать только `transform`, `opacity` и `clip-path`. Никогда width / height / top / left / margin.
- Все анимации внутри `gsap.matchMedia()` с ветками: десктоп, мобильный, `(prefers-reduced-motion: reduce)`.
  В reduced-ветке движения нет, весь контент сразу виден.
- Контент виден без JS: `<html class="no-js">`, скрипт меняет класс на `js`;
  начальные «скрытые» состояния только под `.js` или через `gsap.set`.
- Lenis синхронизировать со ScrollTrigger:
  ```js
  const lenis = new Lenis();
  lenis.on('scroll', ScrollTrigger.update);
  gsap.ticker.add((t) => lenis.raf(t * 1000));
  gsap.ticker.lagSmoothing(0);
  ```
  Якорные ссылки — через `lenis.scrollTo`.
- SplitText запускать после `document.fonts.ready`; после загрузки картинок — `ScrollTrigger.refresh()`.
- Не повторять одинаковый fade-up на каждой секции: у каждой секции свой приём. Главный «вау»-момент — в hero.
- Кастомный курсор и магнитные кнопки только при `(hover: hover) and (pointer: fine)`.
- Прелоадер не дольше 1.5 с. Не прятать сайт за кнопкой «Войти».
- `will-change` ставить только на время анимации.
- Цель — стабильные 60 fps. Если эффект тормозит на телефоне, упростить его в мобильной ветке.

## Как работать
- Перед большим изменением — план из нескольких пунктов, потом делать.
- По мелочам не спрашивать: решать самому и коротко отчитаться в конце.
- Спрашивать только перед сменой стека, удалением файлов и `git push`.
- Маленькими шагами: после каждой секции — сервер, скриншоты, проверка.
- После каждого рабочего этапа — `git commit` с понятным сообщением.
- Нашёл грабли (баг, особенность библиотеки) — допиши строку в «Заметки».

## Дизайн-система
- Палитра (утренний туман над Днепром + кофейная ягода): туман `#dfe6e8` (фон), пар `#f6f9f9` (меню), река `#17313f` (тёмные секции), чернила `#0e1c24` (текст, футер), ягода `#c5283d` (кнопки, акцент), крема `#ebc48a` (акцент на тёмном).
- Шрифты: Sofia Sans Extra Condensed 500/700/900 — заголовки, кнопки, навигация, цены (капсом, высокие узкие буквы как столбы пара); Literata — весь текст, курсив для примечаний.
- Сетка и выравнивание: всё по левому краю, контейнер до 96rem, на десктопе 12 колонок со сдвигом фото; фото без скруглений, кнопки-«таблетки».
- Главный запоминающийся элемент: пар. Гигантское слово «ПАРА» поверх живого шейдера пара в hero, буквы улетают вверх при скролле; прелоадер «греет воду» до 100°. Всё остальное спокойное.
- Классы на `<html>`: `js` (JS есть), `reduced` (анимации выключены — ОС или кнопка в футере, ключ localStorage `para-motion`), `is-ready` (hero показан), `is-loaded` (прелоадер убран). Скрытые стартовые состояния — только под `.js:not(.reduced)`.
- Режимы секций вешает JS: `.process.is-pinned`, `.gallery.is-horizontal` (только десктоп ≥900px); без них это обычный список и лента со свайпом.

- Unsplash отдаёт 401 на curl и на /napi: искать фото через Playwright (страница поиска `?license=free`), качать с `images.unsplash.com/photo-ID?fm=webp&q=..&w=..&h=..&fit=crop` — сразу WebP, Pillow не нужен.
- Буквы «ПАРА» в Sofia Sans Extra Condensed 900 шире, чем кажется: слово ≈ 1.75 × font-size. Размер hero считать от этого.
- Колесо мыши застревает в iframe карты — iframe выключен (`pointer-events: none`) до клика по карте.
- В node-скриптах на Windows абсолютный import — только `file:///D:/...`.
- Счётчик прелоадера стартует до ожидания шрифтов (`startCount`), иначе прелоадер растягивается на время загрузки шрифтов.
